ANDE SERENADA — PAKET REPOSITORY LENGKAP

Gunakan seluruh isi folder ini untuk menimpa file repository pada branch main.

Penting: GitHub upload akan menimpa file dengan nama yang sama, tetapi tidak menghapus file yang tidak ada dalam paket. Setelah upload, hapus file duplikat lama .github/workflows/Ande-Serenada-build-apk-FIXED.yml jika masih ada. Sisakan .github/workflows/build-apk.yml.

Ikon web memakai nama file v3 agar Samsung Internet tidak memakai cache ikon lama. Ikon APK menggunakan adaptive foreground berpadding di dalam zona aman 66x66 dari bidang 108x108 dan tanpa layer monochrome eksplisit.

Jangan hapus data/cache/storage browser pada HP. Pergantian file repository tidak menghapus localStorage, tetapi menghapus data browser dapat menghilangkan pembukuan.
