🛟 Penyelamatan Data

Periksa dan keluarkan salinan langsung dari penyimpanan browser yang sedang membuka aplikasi ini. Fitur ini hanya membaca dan menyalin data; tidak menghapus atau mengganti data asli.

Memeriksa penyimpanan perangkat…
Pastikan jumlah data yang terdeteksi sesuai sebelum membagikan atau menyimpan cadangan.

Cadangkan data

Unduh seluruh menu, transaksi penjualan, pengeluaran, dan arsip struk sebagai file JSON. Simpan file ini di tempat yang aman.

Pulihkan data

Impor file cadangan JSON dari aplikasi ini. Data saat ini akan diganti dengan isi file cadangan.


Ekspor tabel

Unduh ringkasan transaksi penjualan atau daftar pengeluaran dalam format CSV yang dapat dibuka di Excel.

Penyimpanan perangkat

Data tersimpan lokal pada browser yang digunakan.

Penting: data disimpan pada browser/perangkat ini (localStorage), bukan di server. Menghapus data browser, memakai mode privat, atau berpindah perangkat dapat membuat data tidak tersedia. Lakukan cadangan secara berkala.
