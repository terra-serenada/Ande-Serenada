ANDE SERENADA — PAKET PENGGANTI REPOSITORY (IKON MONOCHROME + APK)

UNGGAH ISI FOLDER INI KE ROOT REPOSITORY terra-serenada/Ande-Serenada, branch main.
Jangan unggah folder pembungkusnya. Pertahankan struktur .github dan android.

PENTING:
- Workflow hanya satu, dengan nama persis .github/workflows/build-apk.yml.
- Jangan mengganti nama menjadi build-apk-FIXED.yml atau membuat duplikat workflow.
- Folder android/app/src/main/res/mipmap-anydpi-v26 berisi ic_launcher.xml, ic_launcher_round.xml, ic_launcher_foreground.png, dan ic_launcher_monochrome.png.
- Ikon monochrome adalah layer putih-transparan untuk Android Themed Icons; ikon warna tetap memakai logo penuh.
- Aset web menggunakan nama v4 baru untuk menghindari cache ikon lama.

Setelah upload dan commit:
1. Buka Actions.
2. Pilih workflow Build Ande Serenada APK.
3. Pilih Run workflow pada branch main.
4. Pastikan langkah Verify Android project and launcher icon files dan Build installable debug APK berhasil.
5. Unduh artifact Ande-Serenada-APK.

Jangan hapus data browser atau data situs. Penggantian file repository tidak memindahkan atau menghapus localStorage di HP, tetapi pemasangan ulang APK dapat memiliki implikasi data lokal tersendiri.
